# Камень и ветер

Прототип свободного перемещения шести рабочих по трёхмерной карте

## Управление

1. Выберите рабочего на карте, в нижней панели или клавишами 1–6
2. Нажмите на свободное место — рабочий пройдёт весь маршрут до выбранной точки
3. Кнопка со стрелкой у списка рабочих переключает выбор и камеру по кругу
4. Перетаскивание и WASD перемещают камеру, правая кнопка мыши и Q/E поворачивают её
5. Колесо и кнопки +/− меняют масштаб, миникарта позволяет быстро перейти в другую часть карты
6. Кнопка «Сбросить позиции» возвращает всех рабочих к поселению

Все шесть рабочих доступны сразу. Движение не ограничено очками действий или сменой раундов

Карта 61 × 45, поиск пути обходит воду, замок и занятые участки. Через реку можно пройти по мостам

Положение рабочих сохраняется в браузере отдельно от предыдущего стратегического прототипа

Для запуска не нужны сервер или аккаунт. GitHub Pages: https://febirrisameean.github.io/stone-and-wind/

Для локального запуска используйте HTTP-сервер, например команду `python3 -m http.server 8080` из папки игры
