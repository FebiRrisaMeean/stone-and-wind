# Камень и ветер

Десктопный прототип перемещения шести рабочих по трёхмерной карте

## Управление

1. Выберите рабочего нажатием на фигурку, его портрет или клавишами 1–6
2. Нажмите на свободное место — рабочий пройдёт маршрут до выбранной точки
3. При неподвижном курсоре камера следует за выбранным идущим рабочим; движение мыши возвращает свободное управление
4. Подведите курсор к краю окна, чтобы двигать камеру в эту сторону
5. Перетаскивание и WASD перемещают камеру, правая кнопка мыши и Q/E поворачивают её, колесо меняет масштаб
6. Нажатие на миникарту перемещает камеру

Имена рабочих видны на карте только при наведении. Шесть рисованных портретов и случайные имена сохраняются вместе с позицией каждого рабочего

Карта 61 × 45, поиск пути обходит воду, замок, занятые участки и активные маршруты. Через реку можно пройти по мостам

Положение рабочих сохраняется в браузере отдельно от прежнего стратегического прототипа

Для запуска не нужны сервер или аккаунт. GitHub Pages: https://febirrisameean.github.io/stone-and-wind/
