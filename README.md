# Камень и ветер

Пошаговая стратегия на двоих с трёхмерной картой, двумя фракциями и борьбой за центральную крепость

## Как играть

1. Выберите тренировку против ИИ или игру вдвоём на одном экране
2. Выберите фракцию — вы начнёте с замком и шестью рабочими
3. Назначайте рабочих на источники и развивайте своё владение
4. Нажимайте карточку «Рабочие» для переключения камеры между ними по кругу, выводите свободных жителей кнопкой «Вывести рабочего» за одно действие
5. Выбирайте отряды в нижней панели и нажимайте на карту для движения
6. Нажатие на противника открывает прогноз боя
7. Займите центр крепости и удерживайте его три полных раунда подряд

Партия сохраняется в браузере. Камера свободно перемещается перетаскиванием или WASD, поворачивается правой кнопкой мыши или Q/E, масштаб меняется колесом или кнопками. Миникарта позволяет быстро перейти в любую часть долины

Карта 61 × 45, готовой армии на старте нет. Казармы открывают найм защитников. При нуле действий раунд завершается отдельной кнопкой

Графика — стилизованные средневековые миниатюры с различимыми силуэтами и анимациями движения, флагов, работы жителей и боя

## Версия для GitHub Pages

Игра полностью работает в браузере, сервер не требуется

Онлайн-комнаты с разных устройств пока не подключены. Игровой баланс предварительный

Для локального запуска используйте любой HTTP-сервер, например команду `python3 -m http.server 8080` из папки игры

Для публикации включите GitHub Pages из ветки main, папка / (root)

Three.js 0.180.0 включён локально, лицензия MIT находится в vendor/THREE-LICENSE.txt
